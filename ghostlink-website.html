Privacy Policy

Last updated: June 2026

1. No Data Collection

GhostLink collects no personal data whatsoever. We have no servers. We have no database. We cannot collect data even if we wanted to.

2. What Stays on Your Device

All core state and sensitive configuration parameters remain strictly on your physical hardware storage:

  • Your cryptographic key pair
  • Your BIP39 seed phrase (only you know this)
  • Your message history
  • Your contact list
  • Your local settings

None of this ever leaves your device except as encrypted fragments distributed to your own chosen peers.

3. Peer-to-Peer Communication

Messages travel directly between devices using WebRTC connections. The signaling server (used only for initial connection setup) sees only metadata associated with the handshake (timing and IP addresses). It never sees message content, identities, or keys.

4. The Signaling Server

A minimal WebSocket relay assists with the initial WebRTC handshake. It holds no logs or data between sessions. All messages routed through the signaling backend are connection setup signals only — never chat content.

5. Seed Phrase & Recovery

Your 12-word seed phrase is generated locally. We never see it. We cannot recover it. You are solely responsible for keeping it safe.

6. Open Source

GhostLink's source code is public under the GPL-3.0 license. Anyone can verify these claims by reading and compiling the code independently.

7. Changes to This Policy

We will post any policy modifications directly on the GitHub repository. Continued use of the service constitutes acceptance of the current policy terms.
